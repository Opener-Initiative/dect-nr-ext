Core Concepts of DECT NR+ NS3 Simulation

The core idea of DECT NR+ NS3 simulation is to gather simulation results of MAC-to-MAC communication between devices. Therefore, the most important concepts to be simulated are:

  • PHY layer
  • MAC layer
  • DECT NR+ Topology

Each script in NS3 consists of defining the core NS3 networking abstractions such as: nodes, net devices, applications, PHY, MAC, channel, and mobility (physical topology). In this documentation section, it will be presented how the core DECT NR+ concepts were abstracted in the NS3 simulation environment.
